Haru Projector 隐私政策

最后更新：2026-10-28 · English below

Haru Projector 是什么

Haru Projector 是一个开源的电视 / 投影仪桌面（Android 启动器）。用户可以在电视上扫码，用手机登录自己的 Google 账号， 让电视桌面左上角的日程卡片显示自己接下来的日程。

我们读取哪些数据

只申请一个权限：https://www.googleapis.com/auth/calendar.readonly（只读）。电视用它读取：

  • 日历列表（名称、颜色），供用户在电视上选择显示哪些日历；
  • 所选日历中今天和接下来几天的日程：标题、开始和结束时间、是否全天。

不读取、也不会修改：日程描述、参与者、附件、地点以外的其他信息（地点只在用户开启时显示），不创建、修改或删除任何日程，不访问邮件、联系人或任何其他 Google 数据。

数据存在哪里、给谁

  • 授权令牌（refresh token）和读取到的日程只保存在用户自己的电视上，用于在桌面上显示。
  • 没有我们的服务器。日程不会上传到任何第三方，也不会用于广告、分析或训练模型。
  • 登录时手机会经过一个静态网页（haru-projector.github.io/oauth），它只在手机浏览器里把授权码交给同一 Wi-Fi 下的电视，不保存、不转发到别处。

Google 用户数据政策

Haru Projector 对从 Google API 获取的信息的使用和转移，遵守 Google API 服务用户数据政策，包括其中的「有限使用」要求。

如何删除

在电视的日程卡片设置里选「移除账号」，电视会删除令牌和缓存的日程；也可以随时在 Google 账号 → 第三方应用 里撤销 Haru Projector 的访问权限。

Haru Projector Privacy Policy

Last updated: 2026-10-28

Haru Projector is an open-source TV / projector home screen (Android launcher). A user scans a QR code on the TV and signs in with their own Google account on their phone, so the TV's agenda card can show their upcoming events.

Data accessed: one read-only scope, calendar.readonly: the list of calendars (name, colour) so the user can choose which ones to show, and events of the selected calendars for today and the next few days (title, start and end time, all-day flag). Haru Projector never creates, changes or deletes events and accesses no other Google data.

Storage and sharing: the refresh token and the fetched events are stored only on the user's own TV and used only to display the agenda. There is no Haru Projector server; data is not sent to any third party and is not used for advertising, analytics or model training. During sign-in the phone passes through a static page (haru-projector.github.io/oauth) that hands the authorization code to the TV on the same Wi-Fi in the phone's browser and stores nothing.

Haru Projector's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deletion: choose "Remove account" in the TV's agenda card settings, or revoke access at any time at Google Account → Third-party apps.
